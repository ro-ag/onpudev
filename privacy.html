Privacy policy

Effective 31 October 2026. Applies to Brano and to this website.

Summary

Brano runs on your computer and keeps your work on your computer. It has no account system, no analytics and no telemetry. It connects to the internet only when you ask it to, and only to services you choose.

Data Brano stores

  • Your projects, scores and recordings are files you save where you choose. Brano does not upload them.
  • Settings (audio devices, window layout, plug-in scan results, AI provider configuration) are stored in your user profile folder on the same computer.
  • API keys you enter for AI providers are stored locally in that settings folder and are sent only to the provider you configured.

Network connections Brano can make

  • AI assistant (Maestro). Off by default. If you configure a provider, the text you send to the assistant, the context it needs from your project and your API key are sent to that provider's servers (for example Anthropic or an OpenAI-compatible endpoint you choose). Their privacy policy applies to that data. You can instead run a local model, in which case nothing leaves your computer.
  • Instrument downloads. When you choose to install a bundled sample instrument, Brano downloads it from the public URL shown in the dialog (for example a GitHub release). Only the download request reaches that server.

Brano does not check for updates on its own and does not send crash reports.

Microsoft Store

If you install Brano from the Microsoft Store, Microsoft processes the purchase and installation and may show us aggregated acquisition statistics. Microsoft's privacy statement applies to that processing. We do not receive personal data from the Store.

This website

onpu.dev is a static site hosted on GitHub Pages. We set no cookies and run no analytics. GitHub may log requests (IP address, user agent) under the GitHub privacy statement.

Children

Brano is a general-audience tool and does not knowingly collect data from anyone.

Changes and contact

Changes to this policy are published on this page with a new effective date. Questions: support@onpu.dev.
