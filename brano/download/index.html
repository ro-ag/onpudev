Install

  • Windows: install from the Microsoft Store; updates arrive there too.
  • macOS: open the disk image and drag Brano to Applications. Intel Macs are not supported.
  • Linux: unpack the archive and run brano. There is nothing to install.

Verify a download

Compare the SHA-256 shown above with the one of the file you downloaded:

shasum -a 256 Brano_*_arm64.dmg
sha256sum Brano_*_linux_x64.tar.gz
